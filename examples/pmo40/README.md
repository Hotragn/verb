## How the Class C story is constructed

Genuine reviews are pinned at 21 a week, which is the budget. Agents produce 70. Everything approved above the budget line is drift, and everything not approved joins the queue.

The overdraft is 3.31x from week 1 and does not change. Drift takes six weeks to become obvious, because the backlog absorbs it first. That lag is the reason people conclude an overdraft was harmless. It was not. It was queued.

## What is random and what is not

Counts are structural. The generator places exactly N decisions per class per week and exactly M below-floor approvals per week, so the headline figures do not depend on how a particular Python version happens to order its random number stream.

Randomness sets texture only: which project, which reviewer, the exact duration inside a band, which decisions get escalated or reversed.
