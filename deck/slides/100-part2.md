# The operating model

<p class="lead">Processes, roles, governance, technology and metrics, redesigned
around one constraint.</p>

@notes

This is the half of the talk people came for, so mark the transition clearly.

Part 1 was an argument. Part 2 is a design. If they only remember one thing from
here it should be that the five layers are not a maturity model to buy, they are
five questions that each have one right answer once you accept the constraint.

Say the running time. There are five layers and you have about twelve minutes,
so nobody should settle in.
