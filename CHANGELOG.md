# Changelog

All notable changes to VERB are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

The specification and the code are versioned together. A change to a definition
in the README is a change to the specification, and it carries the same version
bump as a change to the arithmetic that implements it.

## [0.1.0] - 2026-08-19

First public release. The specification is stable enough to implement.

### Added

**Specification**
- The verification budget: `VB = (R x H x u) / c`, with the overdraft ratio
  `O = D / VB` and the status bands.
- Agentic verification: `c_eff = c_a + (1 - k) x c`, with the recursion rule,
  the calibration rule and the conservatism rule.
- The four decision classes A, B, C and D, defined by the cost of checking
  rather than by risk, with a classification decision tree and three
  tie-breakers.
- The deployment inversion, and the reclassification moves that go with it.
- The agent role contract: scope, evidence, escalation, revocation.
- The evidence plane: six mandatory fields, plus class-specific additions for
  Class B, Class C, Class D preparation packs and verifier verdicts.
- Six operating metrics: VB, overdraft ratio, silent drift rate, containment,
  escalation precision, reversal latency. The exact silent drift calculation,
  including how the per-class floor is derived and why the signal is the excess
  over a 10 percent baseline.
- Four eval gates with numeric pass criteria: classification, evidence,
  verifier calibration, replay.
- Maturity stages S0 to S4, and the argument for why there is no S5.
- Known limitations, stated plainly, including the queueing question that the
  framework does not answer.

**Schemas**
- `schema/agent-contract.schema.json` and
  `schema/decision-artifact.schema.json`, both JSON Schema draft 2020-12.
- 8 valid fixtures and 30 invalid fixtures, each invalid one breaking exactly
  one named rule, with a manifest tying fixture to rule.

**Python package**
- `vb.budget`, `vb.classify`, `vb.metrics`, `vb.drift`, `vb.gates`, `vb.cli`.
- Standard library only. Full type hints. `py.typed`.
- Console script `vb`, with `budget`, `classify`, `metrics`, `drift` and
  `gates`, each with a `--json` form.

**Examples**
- `examples/pmo40`, a synthetic 40-project PMO over 8 weeks: 4,400 decisions,
  14 reviewers, a calibration sample and gate inputs. Generated by a seeded
  script and reproducible byte for byte.
- `vb budget --input examples/pmo40` reproduces the 3.3x Class C overdraft.

**Calculator**
- `calculator/index.html`, one file, no build step, no framework, no network
  requests. Works opened directly from disk and deploys to GitHub Pages as-is.

**Deck**
- `deck/`, built from markdown sources by a standard-library script into a
  self-contained HTML file. QR codes are generated at build time by
  `tools/qr.py`, a pure-python encoder, rather than fetched from a service.
- A PowerPoint build of the same 18 slides, sharing the speaker notes with the
  HTML so the two cannot drift apart.
- `deck/SCRIPT.md`, the spoken script with timings, cut points and the questions
  to expect.

**Repository**
- Apache 2.0. `CITATION.cff`. An issue template for reporting a measured
  verification cost. GitHub Actions for the test suite, schema validation and
  Pages deployment.
